## 5. Какие элементы и workflows освоены

**Элементы интерфейса (Design):**
- Global Variables: создана переменная primary-color типа Color, применена к фону кнопки.
- Custom Styles: создан стиль для текста, использующий глобальную переменную.
- UI Components: добавлен компонент DatePicker для удобного выбора даты.
- Repeating Group: используется для вывода списка расходов.
- Inputs: поля ввода для суммы, категории и описания.

**База данных (Data):**
- Создан Data Type Expense со следующими полями:
  - Amount (number) — сумма расхода
  - Date (date) — дата расхода
  - Category (text) — категория
  - Description (text) — описание
  - IsConfirmed (yes/no) — подтвержден ли расход
- Вручную добавлены 3 тестовые записи через App Data.

**Workflows (Логика):**
- Create: Action Create a new thing (создание записи на основе данных из Input-полей).
- Read: Вывод списка через Repeating Group с источником данных Do a search for Expenses.
- Update: Action Make changes to a thing (изменение существующей записи Current cell's Expense).
- Delete: Action Delete a thing (удаление записи через Current cell's Expense).
